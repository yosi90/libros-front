# Guías antiguas

Estas guías documentaron entregas incrementales ya cerradas. Se conservan para contexto histórico y trazabilidad con roadmaps o peticiones del front.

No son fuente de verdad. Para comportamiento vigente usar, en este orden:

1. `../../openapi.yaml`.
2. `../../api/ENDPOINTS.md`.
3. `../../realtime/CONTRATOS.md` cuando aplique.

No se deben añadir nuevas decisiones a esta carpeta. Si una guía antigua contradice el contrato vigente, prevalecen las referencias anteriores.
